提示词工作台更新：新增 Animagine 与 Krea2，现在支持五种模型输出

这次更新主要两件事：模型变多了，用起来顺手了。

一、新增两个模型

现在一次能出五种提示词。

MOSS 是中文自然语言。
WAI 是 Danbooru 标签。
Pony 是 score_9 体系。
Animagine XL 是标签加质量词。
Krea2 是英文自然语言描述。

其中 Animagine 和 WAI 用的是同一套标签，提示词基本通用。
Krea2 吃的是完整句子，所以单独走一条输出，不跟标签混在一起。

二、用起来更顺

角色自动补外观。选一个角色，MOSS 会自动带上发色、瞳色、服装，不用每次重写。你自己写的描述优先。

拖标签写中文。把标签拖进自然语言框或草稿区，出来的是中文，不再是英文标签。

扩写保留原角色名。扩写出来的段落会沿用你写的角色名，不会自己编名字，也不会把两个人合成一段。

三、修掉的问题

分栏拖拽。以前拖边界能把右侧面板拖出屏幕，现在有最小宽度限制。

结果区拥挤。模型标签变多之后挤在一起，现在会自动换行，标题和按钮不再被压扁。

发色丢失。描述里写长发、卷发这类细节，发色有时会被漏掉，现在会正确补上对应标签。

角色误判。「百合」「内裤」这类词以前会被当成角色名，现在只认表头里写出的名字。

四、下载

GitHub 搜 prompt workbench，或访问 github.com/Overstar66/prompt-workbench

下载 Source code (zip)，解压后双击 install.bat。
Windows 需要 Python 3.10+，macOS 或 Linux 用 python app.py 启动。

老用户直接 git pull 就行，配置和自定义角色不会丢。
