## 正文

```
提示词工作台更新到 v1.5 了，这次三件事。

【一、新增 Krea2】

工作台现在能一次出五种提示词：

  MOSS   —— 中文自然语言
  WAI    —— Danbooru 标签（Illustrious 系）
  Pony   —— score_9 体系
  Animagine —— 标签 + very_aesthetic 质量词
  Krea2  —— 英文自然语言描述

Krea2 走的是 Qwen3VL 文本编码器，吃的是句子不是标签，
所以它的输出单独拼了一段英文描述，不跟标签混。

注意一点：Krea2 是 CFG=1 的蒸馏模型，负向提示词对它不起作用，
界面上已经标了这个说明，别以为是 bug。

【二、MOSS 现在会自动补角色外观】

以前选个角色，MOSS 只给你名字，发色瞳色服装全靠自己写。
现在会自动带上词库里的默认外观：

  略略略：蓝色超长波浪发、浅蓝渐变发梢、心形呆毛、鲸鱼鳍状耳、
  蓝眼睛、白色蕾丝围裙女仆装、娇小、标准。

你自己在描述里写的内容优先级更高，不会被覆盖。

【三、修了三个影响手感的问题】

1. 分栏拖拽
   以前拖右边界能把「结果」「历史记录」拖出可视区，现在有最小宽度限制。

2. 结果区标签拥挤
   五个模型标签挤在一起会折行，现在自动换行，标题和按钮不再被压扁。

3. 拖标签写中文
   把标签拖进「自然语言框」或「MOSS 草稿」，以前出来的是 smile、beach
   这种英文，现在直接写「微笑」「海边」。

【另外】

解析器认表头的写法多了，这些都能识别：

  两个女生 角色A 角色B
  两个角色角色a角色b
  两个人初音未来，略略略
  4个角色 百合 内裤 角色a 角色b

不会再出现「百合」「内裤」被当成角色名的情况。

【下载】

GitHub 搜 prompt workbench，或直接访问：
https://github.com/Overstar66/prompt-workbench

下载 Source code (zip)，解压后双击 install.bat。
Windows 需要 Python 3.10+，macOS / Linux 用 python app.py 启动。

老用户直接 git pull 就行，配置和自定义角色不会丢。
```
