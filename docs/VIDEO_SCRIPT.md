# 软件演示视频 · 分镜脚本

> 时长目标 3 分钟｜录屏 1920×1080｜OBS 窗口捕获｜30fps 足够
> 配音：剪映「文本朗读」，选「讲解」类音色（如"知性女声"）
> 录制前把浏览器缩放调到 125%，窗口最大化，关掉书签栏

---

## 录制前的准备（30 秒）

1. 打开工作台 `http://127.0.0.1:8901`，Ctrl+Shift+R 强刷
2. 清空已选：
   - 中栏「清空」
   - 下栏「清空结果」
3. 准备两张图放桌面：
   - `demo1.jpg`（一张动漫插画，内容清晰）
   - 备用一张线稿
4. OBS：来源 → 窗口捕获 → 选浏览器窗口；输出 → 1080p / 30fps / 8 Mbps
5. 开「鼠标高亮」（OBS 插件或系统设置里开启指针显示）

## 分镜表

### 镜头 1｜开场（0:00–0:12）

**画面**：工作台首页，鼠标不动

**台词**：
> 写动漫提示词，你是不是也这样：图看了半天不知道怎么写，标签拼来拼去，最后还得切到别的工具。

**操作**：静止 3 秒即可，让观众看清界面

---

### 镜头 2｜它是什么（0:12–0:30）

**画面**：鼠标从上往下缓慢划过头部工具栏（不做点击）

**台词**：
> 这个工具把整条链路放在一个页面里：图反推、AI 扩写、拆标签，最后直接出 MOSS、WAI、Pony 三套提示词。全程本地运行，不开网页端也不用登录。

**操作**：鼠标从「API」滑到「生成结果」，速度慢，约 5 秒

---

### 镜头 3｜路径一：图反推（0:30–1:05）

**画面**：左栏左下角「点此选图反推」虚线框

**台词**：
> 第一种用法，有图就行。点这里选图，或者直接把图拖进来。

**操作**：
1. 点击「点此选图反推 或拖图」
2. 选 `demo1.jpg`
3. 等结果出来（约 2 秒）

**台词**：
> 它会自动识别图片里的角色、服装、姿势，标签直接进到中间的已选里，同时给一段中文描述。

**操作**：鼠标移到中栏，缓慢滚动已选列表，让标签划过屏幕

**台词**：
> 这些标签你可以留着，也可以删掉不想要的。确认之后，点右上角生成结果。

**操作**：点「生成结果」，等右侧出结果，鼠标划过 MOSS 区

---

### 镜头 4｜结果展示（1:05–1:25）

**画面**：右栏结果区

**台词**：
> 三套提示词一次出好，每套都带负向。点右上角复制，直接粘到你的出图工具里。

**操作**：
1. 依次点「MOSS」「WAI」「Pony」三个标签
2. 每次停留 2 秒
3. 点一次「复制」，让观众看到按钮反馈

---

### 镜头 5｜路径二：文字扩写（1:25–2:00）

**画面**：左栏上方输入框

**台词**：
> 第二种用法，只写一句话。比如"一个女孩，樱花开，站在桥上，微笑"。

**操作**：
1. 点击输入框，输入：`一个女孩，樱花开，站在桥上，微笑`
2. 点「AI 扩写」
3. 等 2~5 秒

**台词**：
> 扩写会自动补全发色、眼睛、服装和场景，还会锁住角色设定，不会给你乱改。

**操作**：结果出来后滚动扩写结果

**台词**：
> 觉得可以，就点「拆成标签」或「生成 MOSS」。

**操作**：点「拆成标签」，展示标签进入已选

---

### 镜头 6｜路径三：纯标签拼装（2:00–2:25）

**画面**：左栏分类栏

**台词**：
> 第三种用法，最精确。左边一万八千条标签，搜什么都行。

**操作**：
1. 在搜索框输入 `樱`
2. 展示结果列表
3. 单击两个标签（如"樱花"、"微笑"）
4. 拖一个标签到角色框（展示"归属"效果）

**台词**：
> 标签可以拖进角色框，表示"这个属于她"。点生成结果，标签会按角色分组写进去。

---

### 镜头 7｜亮点快剪（2:25–2:45）

**画面**：快速切换三个亮点，每个 6 秒

**台词**：
> 词库一万八千条，三千个角色自带发色瞳色；画风库五十张，点一下就用；右上角还有一份内置说明书。

**操作**：
1. 点「画风库」，划过缩略图，关闭
2. 点「说明书」，切到「开关」标签，展示 2 秒，关闭
3. 鼠标指向顶部的「NSFW模式」和「润色」

---

### 镜头 8｜结尾（2:45–3:00）

**画面**：切到 GitHub 仓库页（提前开好标签页）

**台词**：
> 项目开源在 GitHub，搜 prompt workbench 就能找到。下载解压，双击安装，两分钟跑起来。链接放在简介和评论区。

**操作**：鼠标划过 README 的三张展示图

## 剪映里的加工顺序

1. 导入录屏 → 按上面的时间点切片，删掉等待和多余操作
2. 「文本」→「智能字幕」自动识别不出台词，所以：
   - 用「文本朗读」逐段粘贴台词 → 生成音频
   - 再把音频拖到对应位置
3. 字幕：「识别字幕」基于 TTS 音频生成，比手打快
4. 片头：即梦/可灵生成 3 秒"蓝紫渐变 + 光点"动画，标题打「提示词工作台」
5. 背景音乐：剪映曲库搜「轻电子」「科技」，音量压到 -22dB
6. 导出：1080p / 30fps / 推荐码率

## 录制小技巧

| 问题 | 处理 |
|---|---|
| 鼠标找不到 | 开 OBS 指针高亮，或录制后用剪映加"点击圈" |
| 等待时间太长 | 剪映里直接切掉，或用 1.2 倍速 |
| 界面太小 | 浏览器缩放 125%，只录窗口不录全屏 |
| 操作失误 | 别停，继续录，剪映里剪掉 |
| 台词对不上 | 先录画面，最后按画面配台词更省事 |
